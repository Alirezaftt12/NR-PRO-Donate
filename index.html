قفل واقعی امکانات

پنل نمایندگی از منوی مدیریت و URL مستقیم قفل است. API ساخت، حذف و تنظیم ربات نماینده نیز بدون لایسنس معتبر Pro اجازهٔ استفاده نمی‌دهد.

فعال‌سازی امن

لایسنس پس از پرداخت فقط روی سرور در config/pro.php وارد می‌شود. مقدار license_key را در GitHub عمومی یا گزارش‌ها قرار ندهید.

انقضا و پرداخت

تاریخ انقضا با license_expires_at کنترل می‌شود. مبلغ، واحد پول و لینک پرداخت در بخش payment تنظیمات تعیین می‌شوند.
